# Daniel Novak - CSC-461-001 - Assignment 2 VR Museum

This project is my take on a VR museum: a museum of arcade games. This topic was chosen based on my passion for arcade games. This museum features 5 exhibits, each of a different arcade game. Each exhibit includes a model of the game being discussed, as well as information panels detailing what game it is and how it is usually played.
